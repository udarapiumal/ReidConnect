ReidConnect is a full-stack smart campus platform developed as a university final year project under the close mentorship of UCSC's Director and Senior Assistant Registrar (SAR). It aims to transform campus life by unifying core university operations into a single digital ecosystem.
Overview
Built to serve 900+ students, ReidConnect digitizes and streamlines everyday academic and administrative processes — from timetable generation to document approvals — while also enhancing student community engagement through a dedicated mobile app.
Key Features

Automated Timetable Generation — Intelligent scheduling engine with clash detection across courses, lecturers, and venues.
Digital Venue Booking — Streamlined reservation system for lecture halls, labs, and event spaces.
PKI-Based Document Signing — Public Key Infrastructure-driven digital signatures to eliminate paper-based approval workflows.
Club Management — Tools for managing clubs, memberships, and subscriptions.
Lost and Found System — Centralized platform for reporting and recovering lost items on campus.
Mobile App — Community feeds, event publishing, and personalized academic and extracurricular tracking.
Report Generation — Automated reporting for administrative oversight.

Tech Stack

Backend: Java
Frontend: TypeScript, React
Mobile: Mobile app (cross-platform)
Security: PKI / Digital Signatures
